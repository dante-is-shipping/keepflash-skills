# KeepFlash Agent Skills

Official agent skills for [KeepFlash](https://keepflash.com).

## Install

```bash
npx skills add dante-is-shipping/keepflash-skills --skill keepflash
```

The `keepflash` skill lets supported AI agents search, read, cite, create, and safely update content in a user's private KeepFlash library. Authentication uses browser authorization; users never need to paste an access token into chat.
